# Firdaus Bashir Ahmed — Recruiter Profile Website

A responsive, static personal profile website based on the uploaded resume and profile photo.

## Files
- index.html — website
- profile.jpg — profile photo
- Firdaus_Bashir_Ahmed_Resume.docx — downloadable resume

## Publish
This is a static website and can be hosted publicly with GitHub Pages, Netlify, Vercel, Cloudflare Pages, or another static host.

Important: the website currently uses the email/phone from the resume. Add your actual LinkedIn URL in `index.html` if you want a LinkedIn button.
